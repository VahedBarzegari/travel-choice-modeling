
# Travel Choice Modeling

This repository documents a Python-based project on travel behaviour and discrete choice modeling using the London Passenger Mode Choice (LPMC) dataset.

## Objectives

- Explore and understand individual travel choice data.
- Develop and estimate discrete choice models.
- Compare model performance and behavioural interpretation.
- Investigate the implications of model selection for travel demand analysis.

## Dataset

London Passenger Mode Choice (LPMC), based on London travel survey data from 2012–2015.

The original dataset is kept in `data/raw/`. Converted and processed datasets are stored in `data/processed/`.

## Project Structure

- `data/`: Raw and processed datasets
- `notebooks/`: Jupyter notebooks for analysis
- `src/`: Reusable Python functions
- `results/`: Analysis outputs
- `requirements.txt`: Python dependencies
